# React D3 Face Visualizer

This is a React application that demonstrates creative SVG rendering and data visualization using D3.js. It includes features like:

- A grid of dynamically generated SVG faces
- Mouse-tracking interactions
- Navigation between different pages
- Fetching and parsing CSV data using D3

## 📦 Features

- ✅ SVG face rendering with props (eyes, mouth, stroke)
- ✅ Mouse tracker (circle follows the cursor inside the SVG)
- ✅ Navigation with React (About Me, Data Visualization pages)
- ✅ CSV parsing using D3 (`d3.csvParse`)
- ✅ Modular component structure
